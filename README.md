# Evde Güçlen PWA

Mobil öncelikli, çevrimdışı çalışabilen kişisel antrenman uygulaması.

## Vercel'e yükleme
1. Bu klasörü bir GitHub reposuna yükleyin.
2. Vercel > Add New > Project > ilgili repo.
3. Framework Preset: Other
4. Build Command: boş bırakın
5. Output Directory: .
6. Deploy.

PWA olarak telefonda açtıktan sonra:
- iPhone Safari: Paylaş > Ana Ekrana Ekle
- Android Chrome: Menü > Uygulamayı yükle / Ana ekrana ekle

Hareket demoları SVG tabanlıdır ve dış API gerektirmez.
